Tentang Proyek
Teknologi yang Digunakan
Sistem ini mengintegrasikan mikrokontroler ESP32 dengan sensor-sensor lingkungan untuk memberikan pemantauan dan respons otomatis secara real-time.
🔌

ESP32 Microcontroller

Otak sistem — menghubungkan semua sensor ke jaringan WiFi dan mengirimkan data ke dashboard web secara real-time.

💨

MQ-2 Smoke Sensor

Mendeteksi konsentrasi asap dan gas berbahaya. Outputnya berupa nilai analog ppm yang diproses ESP32.

🌡️

DHT22 Temperature Sensor

Mengukur suhu dan kelembaban udara dengan presisi tinggi. Range: -40°C hingga 80°C.

Sistem Deteksi Suhu

Sensor DHT22 memantau suhu ruangan secara presisi. Ketika suhu melewati ambang batas 36°C, sistem akan mengaktifkan kipas ventilasi secara otomatis untuk menjaga kenyamanan dan keselamatan.

Garis vertikal menunjukkan threshold 36°C — batas dimana kipas ventilasi diaktifkan otomatis.

Kipas Ventilasi Aktif

Deteksi Kebakaran Fire Detection System
🔥

Sistem Deteksi Kebakaran

Kebakaran terdeteksi melalui kombinasi logika AND antara nilai asap MQ-2 yang sangat tinggi dan suhu yang melewati batas kritis. Seluruh perangkat darurat diaktifkan secara bersamaan.

💻 Logika Arduino (Pseudocode)
// Kondisi sistem berdasarkan pembacaan sensor
bool kebakaran = (mq > 500 && suhu > 36);
bool panas = (suhu > 36);
bool asapRingan = (mq >= 350 && mq <= 500);

if (kebakaran) {
  pump.on(); buzzer.on(); fan.on();
} else if (panas) {
  fan.on(); buzzer.on();
} else if (asapRingan) {
  buzzer.on();
}
